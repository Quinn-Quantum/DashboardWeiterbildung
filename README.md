# DashboardWeiterbildung
Dashboard für eine Weiterbildung bei der IU.

# Voraussetzung
Python 3 ist installiert auf dem Endgerät. Das Projekt ist nicht Smartphone optimiert.

# Installieren mit Git
Projekt clonen von Git und in den Pfad wechseln
```bash
git clone https://github.com/Quinn-Quantum/DashboardWeiterbildung.git
cd DashboardWeiterbildung
```
Virtuelle Umgebung mit Python anlegen. Direkt in dem Ordner DashboardWeiterbildung.
```bash
python -m venv venv
```
Für Windows
```bash
venv\Scripts\activate
oder
.\venv\Scripts\activate
```
Für Mac/Linux
```bash
source venv/bin/activate
```
Pakete installieren
```bash
pip install -r requirements.txt
```
Anwendung starten
```bash
python App.py
```

# Info
Beim ersten Start sollten sich eine txt und eine SQL-Lite Datei anlegen.
Wen dies nicht passiert noch mal neu starten.
