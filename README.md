# DashboardWeiterbildung
Dashboard für eine Weiterbildung bei der IU.

# Instalieren

```bash
git clone <URL-deines-Git-Repositories>
cd <Name-des-Projektordners>
```
```bash
python -m venv venv
```
```bash
venv\Scripts\activate
```
```bash
source venv/bin/activate
```
```bash
pip install -r requirements.txt
```
```bash
python App.py
```
